The problem

Quantum computing promises to simulate molecular interactions at a level classical computers never will — directly relevant to protein folding, drug binding, and materials design. But the tooling is fragmented, expensive, and locked behind institutional walls. A brilliant chemistry student in Kraków, Nairobi, or Manila has no path to this stack.

I started by building the infrastructure myself: a quantum simulator written from scratch, fast enough to run meaningful experiments on a laptop, open enough that anyone can extend it. That's the first step toward a world where the next drug isn't discovered by who has the biggest AWS bill.

Selected work

C++20 · Open Source 2025–2026
libqc — Quantum Computing Library

Statevector quantum circuit simulator built from scratch in C++20 — zero external dependencies, runs on any machine. Implements QNN, quantum kernel SVM, quantum reservoir computing, and VQE. Built specifically so researchers without cloud budgets can run real quantum ML experiments locally.

~400× faster than
PennyLane / Qiskit
VQE · Molecular Simulation 2026
H₂ Ground State via VQE

First proof that libqc can simulate real chemistry: Variational Quantum Eigensolver achieving <10⁻⁶ Ha error against FCI reference. Full H–H dissociation curve scanned at STO-3G level. The same pipeline scales to drug-relevant molecules as hardware improves.
